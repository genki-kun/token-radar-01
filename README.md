A token launch radar that reads the sealed DefiLlama snapshot, learns each category's market-cap/TVL multiple from the 416 protocols that already record a token, and ranks all 342 pre-token protocols by the implied value that model gives them — every rank with its full computation breakdown and a concrete, costed farm plan, presented in a static dashboard with search, filters, a per-protocol detail view and a full method page.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <path-to-snapshot.json>
```
